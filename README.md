# Security Log Analysis and Authentication Investigation

## Project Overview
This project was completed as part of COMP 447 at Loyola University Chicago during Fall 2026.

The objective was to analyze Linux authentication logs to investigate successful and failed login attempts, examine account activity, and identify potential security concerns.

## Technical Skills
- Linux Authentication Log Analysis
- Security Event Investigation
- IP Address Analysis
- Authentication Monitoring
- IP Geolocation
- Security Reporting and Documentation

## Project Description
Analyzed Linux authentication records and created four structured reports:

1. Successful Authentications - Identified successful login events by username, source IP address, and occurrence frequency.
2. Failed Authentications - Examined failed login attempts and associated usernames and source addresses.
3. Legitimate User Authentication Failures - Investigated failed login attempts involving previously authenticated user accounts.
4. Attack Source Analysis - Analyzed failed authentication sources and associated geographic information.

## Security Relevance
Authentication monitoring is an important part of security operations. Analyzing login activity can help security analysts recognize suspicious patterns, investigate potential unauthorized access, and document security findings.
